# محوّل الليرة السورية — قديمة ⇄ جديدة

تطبيق صغير يعمل في المتصفح بلا إنترنت وبلا أي مكتبة خارجية:
تكتب السعر بالعملة **القديمة** أو **الجديدة**، فيعرض لك المبلغ بالعملتين،
ثم **الأوراق النقدية التي يجب أن تعطيها للشخص** بأقلّ عدد أوراق ممكن،
مع **الباقي** الذي تعيده.

## التشغيل

افتح ملف `currency.html` بالنقر المزدوج. هذا كل شيء.

أو عبر خادم محلي (لازم فقط للتثبيت على الهاتف والعمل خارج الشبكة):

```bash
python -m http.server 5173
```

ثم افتح `http://127.0.0.1:5173/currency.html`.

**للتثبيت على الهاتف:** افتحه عبر الخادم واختر من المتصفح «إضافة إلى الشاشة الرئيسية».

## سعر التحويل

رسميًا: **100 ليرة قديمة = 1 ليرة جديدة** (حُذف صفران، وبدأ التداول في 2026/01/01).
السعر ثابت في الشيفرة (`RATE` في `js/currency-core.js`) ولا يحتاج إنترنت.

| الورقة الجديدة | تساوي بالقديم |
|---|---|
| 10 | 1,000 |
| 25 | 2,500 |
| 50 | 5,000 |
| 100 | 10,000 |
| 200 | 20,000 |
| 500 | 50,000 |

الأوراق القديمة المتداولة: 50 · 100 · 200 · 500 · 1,000 · 2,000 · 5,000
(والقطع المعدنية القديمة 5 · 10 · 25 مطفأة افتراضيًا لأنها خرجت من الاستعمال،
ويمكن تشغيلها من قسم الإعدادات).

## ماذا يفعل

1. **التحويل** — اكتب المبلغ واختر عملته، فتظهر القيمة بالعملتين معًا.
2. **الأوراق التي تعطيها** — أقلّ عدد أوراق يساوي المبلغ بالضبط، بالعملة التي تختارها.
3. **الباقي** — اكتب ما دفعه الزبون (بأي من العملتين) فيظهر الباقي بالعملتين،
   والأوراق التي تعيدها له.
4. **الفئات المتوفرة / محفظتي** — أطفئ أي فئة غير متوفرة عندك، أو اكتب عدد الأوراق
   التي تملكها من كل فئة فيحسب البرنامج ضمن ما تملك فقط.

### حين لا يمكن دفع المبلغ بالضبط

أصغر ورقة جديدة هي 10، لذلك مبالغ مثل 15 أو 5 جديدة لا يمكن دفعها تمامًا.
في هذه الحالة يعرض التطبيق **أقرب مبلغ يغطّي المطلوب** (وكم الزيادة)
و**أقرب مبلغ أقل منه** — بدل أن يُظهر نتيجة خاطئة.

كذلك لو كتبت أعداد أوراقك ولم تكفِ، يقول لك ذلك ويعرض أقصى ما يمكن دفعه بما لديك.

## دقّة الحساب

* كل الحسابات تجري بعدد صحيح من **الليرات القديمة** كوحدة داخلية
  (1 جديدة = 100 وحدة)، فلا تتراكم أخطاء الكسور العشرية.
* اختيار الأوراق يستعمل برمجة ديناميكية (لا الطريقة «الجشعة»)، لأن الجشعة تخطئ هنا:
  المبلغ **40 جديدة** لا يُدفع بـ 25+10، بل بأربع أوراق من فئة 10.
* الحل يحترم عدد الأوراق التي تملكها ولا يتجاوزه أبدًا.

## الاختبارات

افتح `test-currency.html` في المتصفح، أو شغّل:

```bash
node js/currency-tests.js
```

تغطّي الاختبارات: قراءة الأرقام العربية والفواصل، سعر التحويل ذهابًا وإيابًا،
مطابقة «أقلّ عدد أوراق» لحلّ مرجعي، الحالات غير القابلة للدفع بالضبط،
حدود المحفظة، والمبالغ الكبيرة.

## الملفات

| الملف | الدور |
|---|---|
| `currency.html` | الصفحة والواجهة |
| `css/currency.css` | التنسيق (يدعم الوضع الليلي تلقائيًا) |
| `js/currency-core.js` | المنطق: التحويل واختيار الفئات (يعمل في المتصفح وفي Node) |
| `js/currency-app.js` | ربط الواجهة بالمنطق وحفظ الإعدادات محليًا |
| `js/currency-tests.js` | الاختبارات الآلية |
| `test-currency.html` | صفحة تشغيل الاختبارات |
| `currency.webmanifest` | التثبيت على الهاتف كتطبيق |

لا تُرسل أي بيانات إلى أي جهة؛ الإعدادات تُحفظ في `localStorage` على جهازك فقط.

## ملف واحد للمشاركة

```bash
node js/build-standalone.js
```

يُنتج `currency-standalone.html`: التطبيق كله (HTML + CSS + JavaScript) في ملف
واحد ≈40 ك.ب، يمكن إرساله عبر واتساب أو البريد ويُفتح بالنقر المزدوج ويعمل بلا
إنترنت. المصدر يبقى `currency.html` وملفاته، والملف الواحد يُبنى منها فلا يوجد
تكرار يدوي — أعد تشغيل الأمر بعد أي تعديل.
